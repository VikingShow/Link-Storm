# 第一阶段范围：本地灵感捕捉闭环 v0.1

日期：2026-06-11

## 1. 阶段目标

第一阶段目标不是完整 HarmonyOS 发布版，而是把核心体验和数据闭环做出来：

```text
打开应用
-> 根据设备形态默认进入语音/手写/文档
-> 保存想法到本地
-> 在想法库中管理
-> 支持导出/导入
```

## 2. 必须实现

### 2.1 三种捕捉方式

1. 语音捕捉：支持浏览器原型中的 MediaRecorder，HarmonyOS 迁移时对应 AudioCapturer/AVRecorder。
2. 手写捕捉：Canvas 绘制和笔迹保存。
3. 文档捕捉：标题、正文、标签、来源链接。

### 2.2 本地想法库

1. 列表查看。
2. 搜索。
3. 类型筛选。
4. 收藏。
5. 归档。
6. 删除。

### 2.3 上下文留存

1. 来源 URL。
2. 来源标题。
3. 手动备注。
4. 截图/图片附件预留。

### 2.4 导出/导入

1. JSON 导出。
2. JSON 导入。
3. 后续扩展 ZIP 和附件导出。

## 3. 暂不实现

1. 悬浮球。
2. 系统分享接收。
3. 真正的 HarmonyOS 分屏。
4. 自动截图。
5. 语音转文字。
6. 手写识别。
7. AI 整理。
8. 跨设备自动同步。
9. 服务器。
10. 账号。

## 4. 技术路线

当前环境没有 HarmonyOS 编译工具，因此第一阶段采用：

```text
可运行本地 Web 原型
+ 与 HarmonyOS 一致的数据模型
+ 与 PRD 一致的交互结构
+ 后续 ArkTS 迁移文档
```

原型位置：

```text
apps/local-capture
```

运行方式：

```bash
npm run dev:capture
```

## 5. 验收标准

1. 应用能在浏览器中启动。
2. 手机宽度默认语音模式。
3. 平板宽度默认手写模式。
4. 桌面宽度默认文档模式。
5. 能创建文档想法。
6. 能创建手写想法。
7. 支持录音能力检测和录音保存。
8. 想法能进入本地列表。
9. 支持搜索和筛选。
10. 支持导出 JSON。
11. 支持导入 JSON。
