# LinkStorm UI 美化与鸿蒙原生组件升级方案

## Goal

将 LinkStorm 当前「一个长页面堆砌所有功能、几乎只用 Button + TextInput + Text」的粗糙 UI，升级为符合鸿蒙设计规范的现代化界面：
- 采用 **Navigation + Tabs** 作为顶层导航架构
- 大量使用鸿蒙**原生组件**（Tabs、Chip、Swiper、Toast、AlertDialog、ListItemGroup、Refresh 等）
- 统一色彩主题、阴影层级、间距节奏
- 想法卡片视觉升级，操作方式从「一行按钮」改为「滑动 + 菜单」
- 捕捉面板从「条件堆叠」改为 Tab 切换
- 详情页使用 Navigation 导航栏 + Scroll 包裹 + 分区折叠面板

## Scope / Non-goals

**包含：**
- Index.ets 全面 UI 重构（Tabs 三页签、捕捉面板子 Tab、想法卡片美化、筛选栏 Chip 化）
- Detail.ets 全面 UI 重构（Navigation 顶栏、Scroll、折叠面板、音频播放条、AI 输出面板）
- 资源文件更新（color.json、string.json 扩充）
- 新建 4 个拆分组件文件，降低 Index.ets 复杂度
- 交互反馈升级（AlertDialog 确认删除、Toast 操作反馈、Toast 草稿保存）

**不包含：**
- 业务逻辑修改（数据层、Repository、Service 不动）
- 状态管理迁移（仍用 @State/@Builder V1 体系）
- 新功能添加（不加新特性，只改 UI 呈现和交互方式）
- 路由架构迁移（仍用 router，不迁移到 Navigation NavPathStack 路由系统——但使用 Navigation 组件作为页面容器以获得导航栏能力）

### 鸿蒙原生组件使用现状

当前仅使用了：`Column`、`Row`、`Text`、`Button`、`TextInput`、`TextArea`、`List`、`ForEach`、`Canvas`、`Stack`、`Image`、`Blank`

**未使用但应使用的鸿蒙原生组件：**
- `Navigation` — 页面导航栏
- `Tabs` / `TabContent` — 页签切换
- `Chip` — 标签/筛选小标签
- `ListItemGroup` — 列表分组
- `Refresh` — 下拉刷新
- `Swiper` — 想法卡片轮播预览
- `Toggle` — 开关（加密备份）
- `Select` — 下拉选择（文件夹选择、冲突策略）
- `Counter` — 数字调节
- `Slider` — 音频播放进度
- `Progress` — 加载/录音进度
- `AlertDialog` / `showAlertDialog` — 确认对话框
- `Toast` / `showToast` — 操作反馈
- `TextPicker` — 日期/类型选择
- `SideBarContainer` — 桌面端侧边栏

### ArkTS 约束

- 不能用 `any`、`unknown`、`as` 断言
- 所有颜色值需为合法 `Color` 类型或 `#RRGGBB` / `#AARRGGBB` 字符串
- `ForEach` key 函数必须返回稳定字符串
- `@Builder` 方法不能与 `@State` 装饰器混用于局部变量
- V1 装饰器体系（@State/@Prop/@Link），不混用 V2

## Design

### 1. Index.ets 架构重构：Navigation + Tabs 三页签

```
Navigation (标题栏: "Link Storm")
├── Tabs (barPosition: BarPosition.Start, 均分)
│   ├── TabContent "捕捉" → CaptureTab
│   ├── TabContent "想法库" → LibraryTab  
│   └── TabContent "设置" → SettingsTab
```

**关键决策：**
- 使用 `Navigation` 作为根容器获得系统导航栏（标题、 subtitle）
- 使用 `Tabs` 拆分三大功能区，用户不再需要在一个超长页面中滚动
- 每个 Tab 内容独立，各自可滚动

### 2. 捕捉面板（CaptureTab）改造

```
Scroll
├── 标题区（设备提示 + 模式说明）
├── 标题输入 TextInput
├── 标签输入 → 下方显示 Chip 标签行（从 tagsCatalog 点击添加）
├── 文件夹选择 → Select 下拉组件（替代 Button 组）
├── 来源输入 Row（来源标题 + 来源链接）
├── 剪贴板读取 Button（小号 + 图标）
├── Tabs (子Tab, barPosition: BarPosition.Start)
│   ├── TabContent "文档" → TextArea + 字数统计
│   ├── TabContent "语音" → 录音控制 + Progress + Slider
│   └── TabContent "手写" → Canvas + 撤销/清空工具栏
├── 备注输入 TextArea
├── 保存/清空操作行（主操作按钮突出）
└── 分享/剪贴板状态 Toast 反馈
```

**原生组件替换：**
- 文件夹选择：`Button 组` → `Select` 下拉
- 录音状态：`Text` → `Progress` 进度条 + 状态 `Badge`
- 语音播放控制按钮：保留但增加图标 + 间距
- 模式切换：`if-else` 条件 → `Tabs` 子页签
- 标签展示：`Button` → `Chip`

### 3. 想法库面板（LibraryTab）改造

```
Column
├── 搜索栏（Search 组件替代 TextInput）
├── 筛选区
│   ├── 类型筛选：SegmentButton（全部/语音/手写/文档）或 Chips Row
│   ├── 状态筛选：Chip 行（收藏/归档/仅本机/待同步/已同步/冲突）
│   ├── 文件夹筛选：Select 下拉
│   └── 标签筛选：Chip 行（从 tagsCatalog 生成）
├── 统计栏（数量 Badge + 清除筛选按钮）
├── Refresh (下拉刷新)
│   └── List / WaterFlow（响应式列数）
│       └── ForEach → IdeaCard
└── 批量操作栏（条件显示，底部固定）
    ├── 已选数量 Badge
    ├── 批量操作按钮组（收藏/归档/删除/移动）
    └── 文件夹/标签批量分配 → Select + Chip
```

**原生组件替换：**
- 搜索：`TextInput` → `Search` 组件（自带搜索图标和清除按钮）
- 类型筛选按钮组 → `SegmentButton` 或 Chip 行
- 状态/标签筛选 → `Chip` 组件（可选中态）
- 文件夹筛选 → `Select` 下拉
- 数量显示 → `Badge` 组件
- 列表 → `Refresh` 包裹 `List`，支持下拉刷新
- 批量操作栏 → 底部固定 `Row`，半透明背景 + 模糊

### 4. 想法卡片（IdeaCard）视觉升级

```
Column (卡片容器)
├── 顶部行
│   ├── 左：类型图标 + 类型标签（Chip 风格，带图标）
│   ├── 中：创建时间（相对时间，如 "3分钟前"）
│   └── 右：收藏心形图标（Toggle/IconButton）
├── 标题 Text（fontWeight: Bold, fontSize: 18）
├── 预览文本 Text（2行截断，灰色）
├── 来源摘要 Text（1行截断，链接蓝色）
├── 标签行（Chip 组件，紧凑排列，最多显示 3 个 + "...N"）
├── 底部行
│   ├── 同步状态 Badge
│   └── 操作：滑动菜单（左滑显示"删除"、"归档"）+ "⋯"更多菜单
└── 选中态：左边框高亮 + 背景色变化
```

**视觉增强：**
- 卡片添加 `.shadow({ radius: 8, color: '#1A000000', offsetY: 2 })` 阴影
- 圆角从 8 增大到 12
- 移除 `border`，改用 `shadow` + `backgroundColor` 区分层级
- 选中态用左侧 4px 高亮条 + 浅色背景
- 操作按钮从 5-8 个缩减为：心形收藏 + 滑动删除/归档 + 更多菜单（打开/编辑/同步状态/仅删记录）

### 5. 详情页（Detail.ets）改造

```
Navigation (标题栏自动带返回)
├── Scroll
│   ├── 来源上下文面板（可折叠）
│   │   ├── 来源标题 + 链接（可点击）
│   │   └── 手动备注
│   ├── 附件/媒体面板
│   │   ├── 手写预览 Image
│   │   ├── 音频播放条（播放/暂停/停止 + Slider 进度 + 时间显示）
│   │   └── 附件操作（选择/打开/清除 → 图标按钮组）
│   ├── 编辑区
│   │   ├── 标题 TextInput
│   │   ├── 标签 Chip 行 + 添加
│   │   ├── 文件夹 Select
│   │   ├── 正文 TextArea
│   │   └── 备注 TextArea
│   ├── AI 输出面板（可折叠）
│   │   ├── 类型选择 Chip 行
│   │   ├── 录入 TextArea
│   │   ├── 已有结果列表（ListItemGroup）
│   │   └── 保存/刷新按钮
│   └── 底部操作栏
│       ├── 保存 Button（主按钮，突出）
│       ├── 收藏 Toggle
│       ├── 归档 Toggle
│       └── 删除 Button（危险红色，需 AlertDialog 确认）
```

**关键改进：**
- 使用 `Navigation` 组件，自动获得带返回按钮的系统导航栏
- 附件路径改为只读展示 + 图标按钮操作，不再暴露 TextInput 直接编辑
- 音频播放增加 `Slider` 进度条
- AI 输出区用 `ListItemGroup` 分组展示
- 面板可折叠（`@State` 控制折叠态 + 动画）
- 删除操作增加 `AlertDialog` 确认

### 6. 设置面板（SettingsTab）改造

```
Scroll
├── 权限管理区
│   ├── 麦克风权限状态 + 重试按钮
│   ├── 悬浮球开关 Toggle + 状态描述
│   └── 剪贴板权限说明
├── 数据管理区
│   ├── 导出（JSON / TXT / Markdown / 分享）→ 菜单式按钮组
│   ├── 导入（文件导入 + ZIP 导入）
│   ├── 冲突策略 Select 下拉
│   └── 截图兜底按钮
├── 备份安全区
│   ├── 加密开关 Toggle
│   ├── 备份密码 TextInput（Password）
│   └── 导入密码 TextInput（Password）
├── 文件夹管理
│   ├── 新建文件夹（名称输入 + 父级 Select + 创建按钮）
│   └── 文件夹列表 List（每项：名称 + 编辑/删除滑动操作）
└── 标签管理
    ├── 新建标签（名称输入 + 创建按钮）
    └── 标签列表（每项：Chip 样式 + 编辑/删除）
```

**原生组件替换：**
- 导出按钮组 → 1 个"导出" Button + `bindMenu` 弹出菜单（JSON/TXT/Markdown/分享/截图兜底）
- 导入按钮组 → 1 个"导入" Button + `bindMenu`（文件导入/ZIP导入/ZIP预览）
- 冲突策略 → `Select` 下拉
- 悬浮球/加密 → `Toggle` 开关
- 文件夹/标签列表项 → `ListItem` + `swipeAction` 滑动删除

## Risks And Compatibility

1. **Chip 组件可用性**：Chip 是 API 11+ 组件，需确认项目 minSDK 版本。若不支持，回退为带样式的 Text/Row 组件
2. **SegmentButton 可用性**：同上，API 12+ 组件，可能需要回退为自定义 Button 组
3. **Navigation 组件与 router 共存**：当前项目用 router.pushUrl 跳转 Detail，使用 Navigation 作为容器组件不会冲突——Navigation 只提供导航栏 UI，页面跳转仍走 router
4. **Search 组件**：API 8+ 即可用，风险低
5. **Select 组件**：API 8+ 可用，但样式自定义有限，可能需要微调
6. **组件拆分后 @State/@Link 传递**：Index.ets 的 @State 需要通过 @Prop/@Link 传递给子组件，需注意状态同步。建议：子组件用 @Prop 接收只读数据，操作回调用函数参数传递

## Rollback

如果 UI 重构导致严重问题，回滚方案：
1. 所有原始文件已在 git 中有版本记录，可直接 `git checkout` 恢复
2. 新建的 components/ 目录可直接删除
3. 资源文件的扩展项可手动删除（添加的颜色/字符串条目有明确注释标记）
4. 建议在开始前创建 git 分支：`git checkout -b feature/ui-redesign`
