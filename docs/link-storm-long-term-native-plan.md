# Link Storm 长期原生推进计划

目标：完整实现 HarmonyOS 原生版 Link Storm，并保持与产品计划一致地持续推进。

## 阶段 1
- 本地捕捉闭环
- 列表/搜索/筛选
- 收藏、归档、删除
- 详情查看与编辑
- 真实导入导出文件流

## 阶段 2
- 语音录制
- 手写草图持久化与预览图
- 文档捕捉增强
- 附件与上下文管理

## 阶段 3
- 标签与文件夹整理
- 更完整的搜索与过滤
- 批量操作
- 更稳的导入导出与冲突处理

## 阶段 4
- 系统分享接入
- 悬浮入口
- 截图兜底
- 设备与分屏适配

## 阶段 5
- AI 整理预留数据结构
- 统计与质量验证
- 形成可交付的原生版本

## Git 推进规则
- 每完成一个可验证里程碑就提交一次 Git
- 每次提交前先记录构建结果和剩余问题
- 保持主线可编译，避免大块未验证改动长时间滞留
